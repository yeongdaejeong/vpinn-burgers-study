2.1 신경망과 경계조건

VectorDiskNet.forward는 각 좌표의 두 해 값을 반환합니다. 배열은 점 개수 × 2입니다. 1-xy.square().sum(...)는 경계 인자이며, 자동미분은 이 인자까지 곱의 법칙으로 미분합니다. 은닉층을 공유해도 마지막 출력 두 개는 독립적인 매개변수를 갖습니다.

경계 오차가 작다는 것은 구조적 경계조건이 작동한다는 뜻입니다. 내부 해의 정확도는 별도로 검증합니다.

2.2 시험함수·약형 잔차·Gram 손실

disk_tests는 경계에서 0인 고정 시험함수와 해석적 미분을 반환합니다. 설정 차수 18은 경계 인자를 곱하기 전 다항식 차수이며 총 190개입니다. Wpsi/Wdx/Wdy의 크기는 190 × 점 개수이고, 행렬곱이 모든 시험함수의 적분을 계산합니다.

weak_residual의 첫 항은 확산의 기울기 내적, 둘째 항은 대류, 마지막 항은 하중입니다. 두 열이 두 PDE에 대응합니다. 대류항은 원래 비보존형을 유지하며 발산 보정 없이 보존형으로 바꾸지 않습니다.

Riu=ε∫Ω∇uθ·∇ψi+∫Ω(uθuθ,x+vθuθ,y)ψi−∫Ωf1ψiGij=∫Ω(ψiψj+∇ψi·∇ψj)J=(Ru)TG−1Ru+(Rv)TG−1Rv

시험함수의 계수 벡터를 c라 하면 잔차는 cᵀR, H1 노름 제곱은 cᵀGc입니다. 따라서 크기 1인 시험함수에서 잔차의 제곱을 최대화한 값이 RᵀG⁻¹R입니다. 동일한 유한 시험공간에서 기저를 일관되게 바꾸어도 같은 양을 측정합니다. 전체 무한차원 쌍대 노름과는 구분합니다.

Gram 행렬은 시험함수의 H1 내적입니다. 단순 잔차 제곱합의 기저 스케일 의존성을 처리하며, G=LLᵀ의 삼각행렬 풀이로 손실을 계산합니다. create_graph=True가 공간 미분을 거쳐 매개변수까지 역전파하게 합니다. Gram 행렬은 PDE Jacobian이 아닙니다.

def first_derivatives(model,points,training=True):# 좌표를 공간 미분 대상으로 만듭니다. detach는 좌표의 이전 그래프만 끊으며 모델 매개변수는 유지됩니다.    xy=points.detach().requires_grad_(True)# 좌표별 두 출력 uv의 크기는 N×2입니다.    uv=model(xy)# u의 공간 기울기 [u_x,u_y]를 구합니다. 학습 중 create_graph=True로 매개변수 역전파를 유지합니다.    du=torch.autograd.grad(uv[:,0].sum(),xy,create_graph=training,retain_graph=True)[0]# v의 공간 기울기 [v_x,v_y]도 계산합니다. 점별 독립 MLP이므로 출력 합의 미분이 각 점 미분을 줍니다.    dv=torch.autograd.grad(uv[:,1].sum(),xy,create_graph=training,retain_graph=training)[0]    return uv,du,dv  def weak_residual(model,rule,epsilon,training=True):    uv,du,dv=first_derivatives(model,rule.xy,training)# 두 열을 [u_x,v_x] 순서로 묶어 N×2 배열을 만듭니다.    grad_x=torch.stack((du[:,0],dv[:,0]),dim=1)# 두 열은 [u_y,v_y]입니다. 행은 적분점, 열은 방정식 성분입니다.    grad_y=torch.stack((du[:,1],dv[:,1]),dim=1)# 핵심: 대류항은 [u*u_x+v*u_y, u*v_x+v*v_y]입니다. 두 성분이 결합됩니다.    convection=uv[:,0:1]*grad_x+uv[:,1:2]*grad_y# 핵심: 확산 + 대류 - 하중. 확산을 부분적분하여 공간 1차 미분만 사용합니다. 반환 크기는 M×2입니다.    return epsilon*(rule.Wdx@grad_x+rule.Wdy@grad_y)+rule.Wpsi@convection-rule.load  def weak_loss(residual,rule):    """두 잔차 성분의 이산 H1 쌍대 노름 제곱. 역행렬은 만들지 않습니다."""# 핵심: LZ=R을 풉니다. G의 역행렬을 직접 만들지 않습니다.    whitened=torch.linalg.solve_triangular(rule.chol,residual,upper=False)# 두 성분의 합 ∑Z² = R_uᵀG⁻¹R_u + R_vᵀG⁻¹R_v입니다.    return whitened.square().sum()

def strong_residual(model,points,epsilon,forcing):    """독립 진단용입니다. 학습 손실에는 이 함수의 결과를 사용하지 않습니다."""# 좌표를 공간 미분 대상으로 만듭니다. detach는 좌표의 이전 그래프만 끊으며 모델 매개변수는 유지됩니다.# 좌표별 두 출력 uv의 크기는 N×2입니다.    xy=points.detach().requires_grad_(True);uv=model(xy)    gradients=[];laplacians=[]# u와 v 각각의 1차 기울기와 Laplacian을 계산합니다.    for k in range(2):# 2차 공간 미분을 위해 1차 미분의 계산 그래프를 보존합니다.        grad=torch.autograd.grad(uv[:,k].sum(),xy,create_graph=True,retain_graph=True)[0]# 검증용 2차 미분입니다. 기본값 create_graph=False라 이 코드를 그대로 PINN 학습에 쓰면 안 됩니다.        xx=torch.autograd.grad(grad[:,0].sum(),xy,retain_graph=True)[0][:,0]# y 방향 2차 미분도 계산합니다. PINN 학습에서는 여기에도 create_graph=True가 필요합니다.        yy=torch.autograd.grad(grad[:,1].sum(),xy,retain_graph=True)[0][:,1]# 각 성분의 Laplacian은 xx+yy입니다.        gradients.append(grad);laplacians.append(xx+yy)    du,dv=gradients# 두 성분의 비보존형 대류항을 점마다 직접 평가합니다.    adv=torch.stack((uv[:,0]*du[:,0]+uv[:,1]*du[:,1],uv[:,0]*dv[:,0]+uv[:,1]*dv[:,1]),dim=1)# 핵심: 강형 잔차 = 대류 - ε*Laplacian - 우변. 현재 VPINN에서는 학습 후 검증에만 사용합니다.    residual=adv-epsilon*torch.stack(laplacians,dim=1)-source_tensor(xy,forcing)# 두 번째 반환값은 발산입니다. 이 PDE에는 발산 0 조건이 없으므로 오차 지표가 아닙니다.    return residual,du[:,0]+dv[:,1]
성분 차이와 발산은 진단값입니다. 이 문제에 두 성분의 동일성이나 발산 0을 강제하면 원래 PDE에 없는 조건을 추가하게 됩니다.

4.2 Gauss 적분에도 약한·강한 경계 강조 적용

랜덤 실험과 같은 밀도 함수 q와 강조 계수 0.3, 0.7을 사용하되, 난수 대신 변환된 좌표에 Gauss–Legendre 규칙을 적용합니다. 기본 Gauss 자체도 끝점 부근에 점이 몰리므로 면적 균등 랜덤과 같은 점 배치가 아닙니다.

t=F(s)=(1−α)s+αs5,s=F−1(t)

t 구간 [0,1]의 Gauss 점과 가중치를 각각 tᵢ와 ωᵢ라 합니다. F는 단조 증가하므로 이분법으로 sᵢ를 구하고 반지름을 그 제곱근으로 둡니다. 각도는 기존과 같은 등간격 점입니다. F(s) ≤ s이므로 같은 Gauss 점은 기본 배치보다 바깥쪽으로 이동합니다. 강조 계수가 클수록 더 많이 이동합니다.

wij=πωinθq(si),q(s)=1−α+5αs4

이 가중치는 ds = dt/q(s)의 변수변환 보정입니다. 랜덤 점의 π/[Nq(s)]와는 달리 Gauss 가중치 ωᵢ가 들어갑니다. 잔차·Gram·하중 모두 이 가중치로 조립하며 가중치 합을 강제로 정규화하지 않습니다. 같은 연속 면적 적분을 겨냥하지만 유한 점수에서 적분 오차는 달라집니다.

분포와 적분 정확도를 구분합니다. 같은 q를 사용해도 결정론적 Gauss 점의 실제 개수 비율이 랜덤 표본의 기대 비율과 같지는 않습니다. 좌표변환 뒤에는 다항식도 t에 대한 비다항식이 될 수 있으므로, 기본 Gauss의 다항식 정확 적분 성질을 그대로 주장하지 않습니다. 제조해 적분 잔차와 공통 독립 약형·강형 잔차를 함께 비교합니다.

Gauss 세 조건 모두 점 개수별 반지름×각도 분해는 20×64, 20×128, 40×128입니다. 각 조건의 적분점은 5개 시드에서 동일하며 시드는 신경망 초기화만 바꿉니다. 총 6개 배치 × 3개 점 개수 × 5개 시드 = 90개 실행입니다.

4.4 평균과 표준오차

e¯=15∑j=15ej,SE=se5

ej는 j번째 시드에서 얻은 오차 값이며, e¯는 5개 오차의 평균입니다. se는 이 5개 오차의 표본 표준편차로, 시드에 따라 결과가 얼마나 달라지는지 나타냅니다.

se=14∑j=15(ej−e¯)2

분모 4는 표본 수 5에서 1을 뺀 값입니다. SE는 평균의 표준오차이며, 위 식처럼 표본 표준편차를 표본 수의 제곱근으로 나누어 계산합니다. 그림의 평균 ± SE는 평균 추정의 변동을 표시하며, PDE 오차 상한이나 95% 신뢰구간이 아닙니다. 강형 잔차 그래프에도 같은 계산을 적용합니다. 평균 오차는 각 실행의 오차를 평균한 값으로, 평균 해를 만든 뒤 구한 오차와 다릅니다.

5. Gauss와 랜덤, 오차는 얼마나 다른가?

이 설정에서는 Gauss가 랜덤 세 조건보다 작은 P3 오차를 보였습니다. 점 개수가 같아도 적분 정확도는 같지 않습니다.

L2는 영역 전체의 차이, 표본 L∞는 평가점에서의 최대 차이, 강형 RMS는 PDE 위반 정도입니다. L2·L∞는 P3 대비 상대 오차(%)이며, 강형 RMS는 백분율이 아닙니다. L∞는 연속 영역 전체의 엄밀한 최댓값이 아닙니다.

9. Q&A — 제조해와 신경망 학습

두 과정을 나눠 생각하면 이해하기 쉽습니다.

  • 제조해 검사: 정답을 아는 함수를 넣어, 잔차를 계산하는 코드가 맞는지 확인합니다.
  • 신경망 학습: 정답을 모르는 실제 문제에서, 잔차가 작아지도록 가중치 θk를 조정합니다.

같은 간단한 문제로 두 과정을 연결해 보겠습니다.

1. 우리가 풀고 싶은 문제

다음 미분방정식을 생각합시다.

−u″(x)=2,0<x<1,u(0)=u(1)=0.

이 문제의 정확한 해는

u(x)=x(1−x)

입니다. 실제 문제에서는 정확해를 모를 수 있지만, 여기서는 원리를 이해하기 위해 답을 아는 문제를 사용합니다.

2. 제조해 검사: “미분과 잔차 계산을 제대로 구현했나?”

먼저 사람이 검증용 함수를 정합니다.

u*(x)=x(1−x)=x−x2.

손으로 미분하면

u*′(x)=1−2x,u*′′(x)=−2.

따라서 이 함수가 해가 되도록 만든 우변은

f*(x)=−u*′′(x)=2

입니다. 이처럼 함수를 먼저 정하고, 그 함수에 맞는 우변을 계산하는 것이 제조해 방법입니다.

이제 코드가 계산한 잔차를 확인합니다.

r(x)=−u*′′(x)−f*(x).

정상적인 코드라면

r(x)=−(−2)−2=0

이 나옵니다.

반대로 확산항의 부호를 잘못 구현해서 +u*′′−f*를 계산했다면

rwrong(x)=−2−2=−4

가 나옵니다. 답이 0이어야 한다는 것을 알고 있으므로 오류를 발견할 수 있습니다.

# 개념을 보여 주는 코드
u = manufactured_function(x)       # 사람이 정한 고정 함수
uxx = second_derivative(u, x)      # 코드의 미분 계산
residual = -uxx - 2

assert residual_is_nearly_zero(residual)

여기에는 학습이 없습니다. 함수도 고정이고, 조정할 가중치도 없습니다.

3. 가중치 학습: “어떤 후보 함수가 방정식을 만족하나?”

이번에는 정확한 해를 모른다고 가정하고, 다음 후보 함수를 사용합시다.

uθ(x)=θx(1−x).

이것은 신경망 대신 가중치 하나만 가진 아주 단순한 모델입니다.

가중치 후보 함수 모양
θ=0 0 평평한 함수
θ=0.5 0.5x(1−x) 낮은 포물선
θ=1 x(1−x) 정확한 해
θ=2 2x(1−x) 너무 높은 포물선

어떤 θ에서도 양 끝의 경계조건은 만족합니다. 따라서 학습에서는 포물선의 높이를 조정해 내부 방정식까지 만족시키면 됩니다.

후보 함수를 PDE에 대입하면

uθ′′=−2θ,rθ=−uθ′′−2=2θ−2.

잔차의 제곱을 손실로 두면

J(θ)=(2θ−2)2.

이 손실은 θ=1일 때 0입니다. 학습 알고리즘에는 “정답은 θ=1”이라고 알려주지 않습니다. 손실의 기울기가 그쪽으로 이동할 방향을 알려줍니다.

J′(θ)=8(θ−1).

경사하강법은

θnew=θ−ηJ′(θ)

로 갱신합니다. 예를 들어 η=0.1이면,

현재 θ 기울기 J′(θ) 다음 θ
0 −8 0.8
0.8 −1.6 0.96
0.96 −0.32 0.992

가중치를 늘리는 방향으로 움직여 정확해에 가까워집니다. 반대로 θ=2에서 시작하면

2→1.2→1.04→1.008

처럼 가중치를 줄이며 접근합니다.

기울기 자체를 줄이려는 것이 아니라, 기울기를 이용해 손실을 줄이는 것입니다.

4. VPINN에서는 이 과정을 ‘약형 잔차’로 수행합니다

같은 문제에 시험함수

ψ(x)=x(1−x)

를 사용해 봅시다. 부분적분한 약형 잔차는

R(θ)=∫01uθ′(x)ψ′(x)dx−∫012ψ(x)dx.

여기에 uθ=θx(1−x)를 넣으면

R(θ)=θ∫01(1−2x)2dx−2∫01x(1−x)dx=θ−13.

역시 θ=1에서 잔차가 0입니다.

현재 노트북처럼 H¹ Gram 값을 사용하면

G=∫01(ψ2+(ψ′)2)dx=1130

이므로 약형 손실은

Jweak(θ)=R(θ)2G=1033(θ−1)2.

앞의 강형 손실과 크기는 다르지만, 이 예시에서는 둘 다 같은 θ=1에서 최소가 됩니다.

VPINN 학습도 이렇게 작동합니다.

R = weak_residual(model, rule, epsilon)
loss = weak_loss(R, rule)

optimizer.zero_grad()
loss.backward()   # 각 가중치를 바꾸면 손실이 어떻게 변하는지 계산
optimizer.step()  # 그 정보를 이용해 가중치 갱신

5. 실제 신경망의 θk는 무엇을 바꾸나요?

위 예시에서는 가중치 하나가 포물선의 높이만 바꿨습니다. 실제 신경망에는 수많은 가중치와 편향이 있습니다.

예를 들어 작은 신경망은 다음처럼 쓸 수 있습니다.

uθ(x)=x(1−x)[a1tanh(b1x+c1)+a2tanh(b2x+c2)].

여기서

θ=(a1,b1,c1,a2,b2,c2)

입니다.

  • aj: 각 항의 기여 크기를 바꿉니다.
  • bj: 변화의 가파름을 바꿉니다.
  • cj: 변화가 일어나는 위치를 바꿉니다.

이 매개변수들을 함께 조정하면 단순히 높이만 바꾸는 것을 넘어 함수의 형태를 바꿀 수 있습니다.

자동미분으로 계산하는

∂J∂θk

는 **“다른 가중치는 현재 값으로 두고, 이 가중치를 조금 바꾸면 손실이 어떻게 변하는가?”**를 나타냅니다.

6. 현재 Burgers 노트북에 연결하면

구분 제조해 검사 실제 학습
함수 사람이 정한 u*=w, v*=2w 신경망의 uθ,vθ
우변 제조해를 대입해서 계산한 검증용 우변 고정된 (−1,−sin(πy))
바뀌는 것 없음 신경망 가중치와 편향
확인·목적 기대한 잔차가 계산되는지 검사 실제 문제의 약형 손실 최소화
v=2u 관계 검증 함수에만 사용 적용하지 않음

제조해를 조금씩 바꿔 실제 해로 만드는 것이 아닙니다. 제조해로 계산 코드를 검사한 뒤, 별도의 신경망을 실제 PDE에 맞춰 학습합니다.

마지막으로, 간단한 예시에서는 후보 함수에 정확해가 포함되어 있고 손실도 단순해서 쉽게 정답에 도달했습니다. 실제 VPINN에서는 유한한 시험공간·수치적분·비선형 최적화 때문에 작은 학습 손실만으로 정확해에 도달했다고 보장할 수 없습니다. 그래서 학습이 끝난 뒤 독립 잔차와 P3 참조해로 다시 확인합니다.
